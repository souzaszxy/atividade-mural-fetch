
# Meu Mural de Publicações

## Objetivo
Criar uma página que consulta uma API pública usando fetch() e apresenta as publicações em cartões.

## Tecnologias
- HTML
- CSS
- JavaScript puro
- API JSONPlaceholder

## Como executar
1. Abra a pasta no Visual Studio Code.
2. Abra o arquivo index.html.
3. Execute com Live Server.
4. Clique em Carregar publicações.
5. Utilize o campo de busca para filtrar os títulos.

## Perguntas

### 1. O que é uma API e por que usamos fetch()?

Uma API é uma forma de um sistema disponibilizar dados ou funcionalidades para outro sistema. Usamos fetch() para fazer uma requisição HTTP e receber dados da API.

### 2. Qual é o papel de resposta.json()?

O resposta.json() transforma o conteúdo JSON recebido em valores JavaScript, como objetos e arrays.

### 3. Qual a diferença entre filtrar o array localmente e fazer uma nova requisição?

Filtrar o array localmente utiliza os dados que já foram carregados no navegador, sem precisar acessar a API novamente. Uma nova requisição busca os dados na API pela internet.
